# Cursor support (planned)

Official Cursor documentation supports project-level `.cursor/skills/<skill-name>/SKILL.md` and `.agents/skills/<skill-name>/SKILL.md`.

When canonical Skills are ready, install a **copy** of each directory from this repository's `skills/` to the target project's `.cursor/skills/`. Keep project-specific rules and user preferences separately in the target project. Do not overwrite existing Skills without review. Manually invoke Skills from Cursor chat.

No automatic install script or runnable Skills are included in this foundation scaffold.

Reference: https://cursor.com/docs/skills
