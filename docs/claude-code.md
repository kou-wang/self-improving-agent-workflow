# Claude Code support (planned)

Official Anthropic documentation supports project-level `.claude/skills/<skill-name>/SKILL.md` and user-level `~/.claude/skills/`.

When canonical Skills are ready, install a **copy** of each directory from this repository's `skills/` to the target project's `.claude/skills/`. Keep project-specific rules and user preferences separately in the target project. Do not overwrite existing Skills without review. Manually invoke Skills from Claude Code.

No automatic install script or runnable Skills are included in this foundation scaffold.

Reference: https://code.claude.com/docs/en/skills
