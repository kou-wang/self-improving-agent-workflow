# Canonical workflow Skills

This folder contains the five shared Skills:

1. [learn-requirement](learn-requirement/SKILL.md)
2. [investigate](investigate/SKILL.md)
3. [make-plan](make-plan/SKILL.md)
4. [execute](execute/SKILL.md)
5. [review-skill](review-skill/SKILL.md)

Use the [installer](../scripts/install.py) to put these Skills in a target Cursor or Claude Code project, or follow the [Quickstart](../docs/quickstart.md).

Every Skill checks the target project's `.agent-workflow/project-rules.md` and `.agent-workflow/user-preferences.md` if present. Do not place project-specific secrets or private business policies in these shared files.
